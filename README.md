# Sistema para oficinas de autoelétricas

Aplicação inicial para organizar cadastros e ordens de serviço de uma oficina elétrica automotiva.

## Como usar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências ou configurar um servidor.

1. Cadastre clientes e fornecedores.
2. Cadastre produtos e serviços no mesmo catálogo. Para produtos, informe custo, preço de venda e estoque; o lucro unitário é calculado automaticamente.
3. Cadastre os veículos e vincule cada um ao cliente proprietário.
4. Crie ordens de serviço com problema relatado, diagnóstico, status e os produtos/serviços utilizados.

Os registros ficam salvos no armazenamento local do navegador e não são sincronizados entre dispositivos. Faça cópias de segurança dos dados antes de limpar os dados do navegador. O lucro das ordens é uma estimativa calculada com os custos registrados nos itens.
